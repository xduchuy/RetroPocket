❓ HOW TO PLAY ❓

DESKTOP CONTROLS:

  • Arrow Keys / WASD: Move / Rotate / Change Lanes
  • Spacebar: Shoot / Jump / Flap / Stack
  • Mouse: Tap on canvas for Memory Tiles & Minesweeper

MOBILE CONTROLS:

  • Virtual D-Pad & Action Buttons: Slide or tap to steer
  • Canvas Touch: Tap to play Memory/Minesweeper
  • Minesweeper flag: Press and hold (>350ms) to flag

SETTINGS:

  • 🌐 Language: Toggle EN/VI
  • 🔊 Sound: Toggle synth SFX
  • ⚙️ Difficulty: Selected before entering each game
